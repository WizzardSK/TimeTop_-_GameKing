# TimeTop_-_GameKing

Thumbnails for TimeTop GameKing games, laid out as [libretro-thumbnails](https://github.com/libretro-thumbnails), named after the games' MAME short names, as the MAME `gameking` software list has them.

Snaps, titles from AntoPISA's [progetto-SNAPS MAME Software List Resources](https://www.progettosnaps.net/softwareresources/).
